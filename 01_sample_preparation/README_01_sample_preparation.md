# 01 Sample Preparation

This module prepares GISAID influenza data for downstream multiple-sequence alignment, trimAl trimming, and IQ-TREE phylogenetic analysis. It merges metadata and FASTA files, separates the eight influenza gene segments, cleans metadata, renames FASTA headers, summarizes HA samples, performs stratified sampling, extracts the same isolates from all segments, and removes duplicate reference sequences.

## Workflow

Run the scripts in the following order:

```text
prepare_samples.py
        ↓
generate_simplified_metadata.py
        ↓
rename_fasta_headers.py
        ↓
summary_count.py
        ↓
sample.py
        ↓
extract.py
        ↓
SeqKit.py
```

`run.sh` is a wrapper for `prepare_samples.py`.

## Requirements

- Python 3.9 or later
- pandas
- NumPy
- Biopython
- openpyxl for `.xlsx` files
- xlrd if `.xls` input files are used

```

```

## Input requirements

Place all raw Excel metadata and FASTA files in:

```text
01_sample_preparation/input/
```

The first script searches this directory recursively by default.

Supported Excel extensions:

```text
.xls  .xlsx
```

Supported FASTA extensions:

```text
.fasta  .fa  .fas  .fna
```

The Excel metadata must contain an `Isolate_Id` column. Later cleaning and sampling steps also use the following columns:

```text
Isolate_Id
Continent
Country
Region
Location
Isolate_Name
Collection_Date
Clade
Host
```

Each FASTA header must contain a gene-segment name and use `|` as the field separator. By default, `prepare_samples.py` reads the fourth field (Python index `3`) as the isolate ID. For example:

```text
>A/duck/example/2022|HA|other_field|EPI_ISL_123456
```

## Running the pipeline

Start from the project root:

```bash
cd /Users/YingCao/Desktop/7-pipeline-msa-trimmal-iqtree-smot
```

### 1. Merge, split, and initially deduplicate the data

```bash
bash 01_sample_preparation/scripts/run.sh
```

This step:

- merges all Excel metadata files;
- merges all FASTA files;
- separates sequences into `MP`, `HA`, `NA`, `PB2`, `PB1`, `PA`, `NP`, and `NS`;
- deduplicates each segment by exact sequence content, retaining the first occurrence;
- matches FASTA isolate IDs to metadata;
- creates an input manifest and quality-control summary.

The main outputs in each segment directory are:

```text
{SEGMENT}.fasta
{SEGMENT}_dedup.fasta
{SEGMENT}_metadata.csv
{SEGMENT}_metadata.xlsx
{SEGMENT}_metadata_simplified.xlsx
```

The script can also be run directly:

```bash
python3 01_sample_preparation/scripts/prepare_samples.py \
  --input-dir 01_sample_preparation/input \
  --output-dir 01_sample_preparation/output
```

Optional arguments:

- `--all-sheets`: read every Excel worksheet instead of only the first one.
- `--no-recursive`: do not search input subdirectories.
- `--genes`: provide a custom list of gene segments.
- `--id-column`: change the metadata ID column; the default is `Isolate_Id`.
- `--header-id-index`: change the position of the ID in pipe-delimited FASTA headers; the default is `3`.

### 2. Generate cleaned, simplified metadata

```bash
python3 01_sample_preparation/scripts/generate_simplified_metadata.py
```

For every segment, this script reads `{SEGMENT}_metadata.xlsx` and writes:

```text
{SEGMENT}_metadata_simplified.xlsx
```

It performs the following operations:

- removes whitespace from column names and metadata values;
- converts valid dates to `YYYY-MM-DD` and uses `Unknown_Date` for unrecognized dates;
- extracts continent, country, and region values from `Location`;
- classifies samples into geographic regions using `Location`;
- adds `Source=GISAID` and the segment name;
- retains the `Host` field;
- constructs a standardized `strain` field.

### 3. Rename deduplicated FASTA headers

```bash
python3 01_sample_preparation/scripts/rename_fasta_headers.py
```

This script matches `{SEGMENT}_dedup.fasta` to the simplified metadata by `Isolate_Id`. It rewrites each matched header as:

```text
Isolate_Name|Collection_Date|Isolate_Id|Subcontinent
```

Output:

```text
{SEGMENT}_dedup_renamed.fasta
```

Sequences without matching metadata are excluded from the renamed FASTA and reported as `skipped` in the terminal.

### 4. Summarize the HA sample distribution

```bash
python3 01_sample_preparation/scripts/summary_count.py
```

This step processes HA only. It counts samples by:

- subcontinent;
- collection year;
- reclassified host category.

Host values are grouped into:

```text
Human
Dairy cow
Chicken
Duck
Goose
Other Animal
Wild Bird
```

Output:

```text
01_sample_preparation/output/genes/HA/HA_summary.xlsx
```

### 5. Perform stratified HA sampling

```bash
python3 01_sample_preparation/scripts/sample.py
```

Sampling is stratified by collection year, subcontinent, and host category. The rules are:

- the target sample size is 5,200;
- strata containing five or fewer samples are retained in full;
- strata containing more than five samples receive a minimum of five samples;
- the remaining slots are allocated in proportion to the remaining capacity of each stratum;
- random seed `42` is used for reproducibility;
- `EPI_ISL_1254` is always retained.

Outputs:

```text
01_sample_preparation/output/genes/HA/HA_metadata_5000sample.xlsx
01_sample_preparation/output/genes/HA/HA_New_Summary_Table.xlsx
Data/reference ID.csv
```

`Data/reference ID.csv` becomes the isolate list used to select corresponding records from all eight segments.

### 6. Extract the reference isolates from all segments

```bash
python3 01_sample_preparation/scripts/extract.py
```

This script reads `Data/reference ID.csv` and extracts matching metadata and sequences from every segment. Records are written in the same order as the reference ID list.

Outputs for each segment:

```text
{SEGMENT}_metadata_reference.xlsx
{SEGMENT}_reference.fasta
{SEGMENT}_missing_reference_IDs.csv
```

The missing-ID report records whether each selected isolate was found in the segment metadata and FASTA file. It can therefore be used to identify samples with missing gene segments.

### 7. Deduplicate the extracted reference sequences with SeqKit

```bash
python3 01_sample_preparation/scripts/SeqKit.py
```

For each segment, the script runs the equivalent of:

```bash
seqkit rmdup -s -i input.fasta -o output.fasta
```

- `-s` deduplicates by sequence content rather than header.
- `-i` ignores sequence letter case.

The metadata are then filtered and reordered to match the retained FASTA records.

Final outputs:

```text
{SEGMENT}_reference_dedup.fasta
{SEGMENT}_metadata_reference_dedup.xlsx
```

These files can be used as inputs for downstream alignment, trimming, and phylogenetic-tree construction.

## Quality-control outputs

### `qc_summary.xlsx`

Reports, for every segment:

- original sequence count;
- sequence count after initial deduplication;
- number of duplicates removed;
- number of isolate IDs recognized in FASTA;
- number of matching metadata rows.

### `unassigned_sequences.fasta`

Contains sequences for which none of the eight gene names could be recognized in the FASTA header. A large number of unassigned records usually indicates an incompatible header format.

### `{SEGMENT}_missing_reference_IDs.csv`

Shows whether every HA-selected isolate has corresponding metadata and sequence data for each of the other segments.

### SeqKit terminal report

Reports sequence counts before and after final deduplication, duplicate counts, headers without recognizable IDs, and retained FASTA IDs missing from metadata.

## Important notes

1. The target size in `sample.py` is **5,200**, although the output filename is `HA_metadata_5000sample.xlsx`. Use the terminal report or Excel row count as the authoritative sample count.

2. `sample.py` requires and forcibly retains `EPI_ISL_1254`. The script stops if this ID is absent from `HA_metadata_simplified.xlsx`. Edit `REQUIRED_ISOLATE_IDS` to replace or remove this requirement.

3. `extract.py` and `SeqKit.py` contain the following hard-coded project path:

   ```text
   /Users/YingCao/Desktop/7-pipeline-msa-trimmal-iqtree-smot
   ```

   Update `PROJECT_ROOT` in both scripts if the project is moved or run by another user.

4. Both `prepare_samples.py` and SeqKit deduplicate by sequence content. When multiple isolates have identical sequences, only the first record is retained; the other isolate IDs are not represented in the deduplicated result.

5. `rename_fasta_headers.py` reads the isolate ID from the fourth pipe-delimited field of the original FASTA header. If the input format differs, adjust the code or use the correct `--header-id-index` during the first step.

6. `extract.py` and `SeqKit.py` recognize IDs matching `EPI_ISL_` followed by digits. IDs in another format cannot be extracted from FASTA headers.

7. Several scripts remove all whitespace from metadata values. For example, `Hong Kong` becomes `HongKong`. This is the current expected behavior.

8. Host values that do not explicitly match the human, domestic-animal, or other-mammal rules are classified as `Wild Bird`. Review this classification before interpreting the summary or sampling results.

9. After the first run, inspect the following in order:

   ```text
   qc_summary.xlsx
   unassigned_sequences.fasta
   skipped counts reported by rename_fasta_headers.py
   HA_summary.xlsx
   actual sample count reported by sample.py
   missing_reference_IDs.csv for every segment
   SeqKit deduplication statistics
   ```
